## Data Description:

Both metrics and log data were collected from Product Review Microservice Platform with hundreds of system entities invovled. Four different types of real faults (including DDoS attack, external storage failure, node resource contention stress test, and noisy neighbor issue) were simulated. 

## Citation:

Lecheng Zheng, Zhengzhang Chen, Dongjie Wang, Chengyuan Deng, Reon Matsuoka, and Haifeng Chen: LEMMA-RCA: A Large Multi-modal Multi-domain Dataset for Root Cause Analysis. CoRR abs/2406.05375 (2024)
