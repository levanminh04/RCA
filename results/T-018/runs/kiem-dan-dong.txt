   58| Every RCA pipeline has, at least implicitly, two stages: a retriever that produces a candidate set C and
   59| a reranker that orders C. The fraction of true causes inside C, which we call Retrieval@K for a set of
   60| size K, is a hard ceiling on any downstream ranker, since no reranker can recover a candidate it was
   61| never shown, yet existing evaluation collapses both stages into a single score, making it impossible to
   62| determine which stage is responsible for failure. In propagating-fault systems, deviation magnitude
   63| alone is insufficient for retrieval since the root cause is suppressed beneath downstream effects, and
   64| the recency assumption fails because anomaly detection fires on detected deviations rather than
   65| true fault onset. Structure-based methods [10�12] face a further obstacle: ranking on their learned
   66| causal graphs is unreliable, whether the graphs are learned on short fault windows, on retrieved pools
   67| guaranteed to contain the cause, or on multi-day normal corpora (Section 7 and Appendix J), and
   68| expert-specified graphs are rarely available in practice [11]. The result is a literature where a method
   69| that never retrieves the true cause and one that retrieves but mis-ranks it appear identical under any
   70| rank-based metric, yet require categorically different fixes.

  323| 5 A Two-Stage Remedy: Retrieval Then Reranking
  324| 
  325| The decomposition makes the two failure modes independently addressable. We instantiate a two-
  326| stage pipeline (Figure 1) as a validation instrument: closing each gap requires categorically different
  327| interventions, and progress on one does not substitute for the other.
  328| 
  329| 5.1 Stage 1: Multi-Signal Retrieval
  330| 
  331| Retrieval produces a candidate set C of at most K sensors that maximizes 1[m  C]. Magnitude
  332| alone is insufficient when downstream sensors are rank-displaced above the cause, so we combine
  333| three complementary signals, each targeting a distinct fault regime (Section 7).
  334| 
  335| Deviation magnitude mag: normalized shift of each sensor from its baseline window. Effective
  336| when the cause produces the largest amplitude change (direct faults).
  337| 
  338| Earliest onset ons: each sensor's first-deviation timestamp within the fault window, earliest first.
  339| Recovers the precedence signal of Section 4.1 when amplitude at the source is suppressed (HVAC-
  340| style gradual drifts).
  341| 
  342| Discrete state-change stc: whether a discrete-valued sensor leaves its baseline mode, ranked by
  343| when it first does. Targets binary actuator or mode-switch faults whose signature is a discrete event
  344| rather than a continuous shift (SWaT-style abrupt transitions).
  345| 
  346| The budget K is split evenly across the signals unless noted, and the deduplicated union forms C
  347| (|C|  K). These three signals are illustrative, not a fixed prescription: each targets a regime we
  348| observed in our benchmarks, and a system that surfaces faults through a different signature (e.g.,
  349| spectral shifts, correlation breaks) would warrant adding the corresponding scorer.
  350| 
  351| 5.2 Stage 2: LLM Reranking
  352| 
  353| Given C, the reranker answers a different question: which candidate is most likely the true cause?
  354| For each si  C we build an evidence record (deviation magnitude, time of first onset, baseline and
  355| fault-window means with absolute and relative shift), pass all records in a single prompt to an LLM,
  356| and read off the returned permutation . An optional domain-knowledge document D describing
  357| system architecture and propagation pathways is injected into the system prompt; unlike graph-based
  358| methods, the reranker accepts D in informal natural language without requiring formalization as a
  359| causal graph. The pipeline is unsupervised, uses no labeled fault traces, and runs a single configuration
  360| across all datasets (Appendix A).
