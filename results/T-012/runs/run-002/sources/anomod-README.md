# AnoMod-A-Dataset-for-Anomaly-Detection-and-Root-Cause-Analysis-in-Microservice-Systems
Collected dataset from socialnetwork and trainticket.

Data has been relocated to [Zenodo](https://zenodo.org/records/18342898) only.

For more details see the paper [pdf](https://dl.acm.org/doi/pdf/10.1145/3793302.3793324).

Ping, K., Mazhar, H., Wang, Y., Song, Y., & Mäntylä, M. V. (2026). AnoMod: A Dataset for Anomaly Detection and Root Cause Analysis in Microservice System. In Proceedings of the 23rd International Conference on Mining Software Repositories (MSR '26), pp. 677–681.
