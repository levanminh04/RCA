# RCA cho FlashTicket

Phần nghiên cứu RCA (chẩn đoán nguyên nhân gốc sự cố) của đồ án "Xây dựng hệ thống bán vé theo kiến trúc phân tán có ứng dụng đồ thị phụ thuộc để giám sát và chẩn đoán sự cố". Người phụ trách: Minh.

- Kế hoạch: `docs/MRP.md`
- Trạng thái hiện tại: `docs/STATE.md`
- Luật làm việc cho agent: `AGENTS.md`

| Thư mục | Nội dung |
|---|---|
| `docs/` | Kế hoạch, trạng thái, quyết định, lý do lựa chọn, bài học |
| `tasks/` | Mỗi task một thư mục: SPEC, LOG, REVIEW. Mẫu ở `tasks/_MAU/` |
| `docs/reference/` | Nguồn gốc chép nguyên văn: DT18, hướng dẫn của cô, bài học v1 |
| `docs/knowledge/` | Kiến thức nền đã lọc (K1–K4), chưa kiểm lại |
| `src/` | Code |
| `results/` | Kết quả từng gói, mỗi gói có README |
| `data/` | Dữ liệu tải về; không đưa vào git |
